# Phone clip folder

Put a 10-30 s copy of real phone footage here (not the original).
Expected coverage:
- normal 4K30 mode (HEVC/H.265, 10-bit if available)
- one portrait clip with real rotation metadata
- one highest-quality mode (HDR10/HLG or 4K60)
- extra metadata/data tracks if the phone writes them
- slow-motion 120/240 fps if available
- multiple audio tracks and real stereo AAC
Files in this folder are gitignored.
